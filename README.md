# Trag viewer

The desktop viewer of Trag, a personal trip-tracking app – built files only, published with GitHub Pages.

Open it at https://stefani1701.github.io/trag-viewer/ and import a Trag backup or a GPX file.
The file is read inside your browser and never uploaded; nothing about you is stored in this repository.
